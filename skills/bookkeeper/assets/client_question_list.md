# Client question list template

Questions for the client about items only they can answer. It's a **draft**: the bookkeeper reviews, edits and sends it themselves. Claude never sends it.

The client reads this between other work, often on a phone. Make each question answerable in one line.

---

**Subject:** [Month] books — [N] quick questions before we close

Hi [Client name],

We're closing [month] for [Company display_name]. Could you help with these by [date]? A one-word answer is fine for most.

1. **[Date] · [Payee] · [$amount]** — [Specific question. E.g. "Was this a business expense? If so, what was it for?"]
2. **[Date] · [Payee] · [$amount]** — [E.g. "We see two payments of this amount three days apart. Was it charged twice?"]
3. **[Customer] · [$amount] received [date]** — [E.g. "Which invoice was this payment for?"]
4. **[Vendor]** — [E.g. "Could you ask them for a W-9? We need it for year-end forms."]

If it's easier, reply with receipts or screenshots and we'll match them up.

Thanks,
[Sender name]

*DRAFT — not sent. Review before sending.*

---

## Tone notes

- Lead every question with date, payee and amount so the client can find it in their bank app.
- One question per item. Never ask "can you explain these 14 transactions?"
- No accounting jargon. "Was this for the business?" beats "Please confirm the GL classification."
- Five to ten questions is the useful maximum. More than that, offer a call.
- If Gmail is connected, offer to save it as a draft. Never send it.
